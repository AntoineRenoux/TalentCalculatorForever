Simple, automatique, partagé

Trois pièces,
un annuaire.

Un addon ne peut ni accéder à Internet ni écrire sur ton disque. GuildProfessions relie donc le jeu, ton ordinateur et Discord pour partager les métiers de la guilde.

01

L’addon, en jeu

Tape /gp pour parcourir les métiers, filtrer par niveau ou recette et consulter les recettes connues d’un artisan. L’addon scanne aussi tes métiers et tes patrons.

02

Le compagnon, sur ton PC

Il transmet tes scans au serveur de la guilde et récupère les données des autres joueurs. Lance-le une fois : il fonctionne ensuite en arrière-plan.

03

Le bot, sur Discord

Trouve un artisan avec /metier who, passe une commande avec /craft order ou déclare un métier manuellement avec /metier set.

Tu joues → L’addon scanne → Le compagnon synchronise → La guilde consulte les données

Sans compagnon

Le canal manuel,
en deux commandes.

Tu peux aussi synchroniser les données par copier-coller. Le compagnon automatise ces échanges, mais il n’est pas obligatoire.

Envoyer tes métiers vers Discord

  1. En jeu, tape /gp, puis choisis « Exporter ».
  2. Copie la chaîne qui commence par GP1!.
  3. Sur Discord, utilise /import et colle-la.

Importer l’annuaire dans le jeu

  1. Sur Discord, utilise /export-addon.
  2. Récupère la chaîne envoyée par le bot.
  3. En jeu, tape /gp, puis choisis « Importer ».

Guide pas à pas

Installation

Choisis ton système pour afficher les instructions correspondantes.

Windows Mac Linux

Windows

  1. Pack tout-en-un : dézippe le fichier, puis lance GuildProfessionsCompanion.exe. Le programme installe l’addon et se lance au démarrage de Windows.
  2. À la carte : place le dossier GuildProfessions dans le dossier Interface/AddOns de WoW, puis lance le compagnon.
  3. En jeu, ouvre chaque fenêtre de métier une fois pour scanner tes recettes. Les données seront envoyées à ta prochaine déconnexion.

Si Windows affiche « Windows a protégé votre PC », clique sur « Informations complémentaires », puis « Exécuter quand même ».

Mac

  1. Télécharge la version Apple Silicon ou Intel selon ton Mac.
  2. Pour l’installation à la carte, place le dossier de l’addon dans World of Warcraft/_forever_/Interface/AddOns/.
  3. Si macOS bloque le compagnon, fais un clic droit sur l’application et choisis « Ouvrir ».
  4. Ouvre chaque fenêtre de métier en jeu pour scanner tes recettes.

Linux

  1. Dézippe le compagnon Linux et rends-le exécutable.
  2. Lance GuildProfessionsCompanion pendant que tu joues.
  3. Pour l’installation à la carte, place l’addon dans le dossier Interface/AddOns de ton installation WoW.
  4. Ouvre chaque fenêtre de métier une fois pour enregistrer tes recettes.

L’annuaire, même hors du jeu

Les commandes Discord

Trouve un artisan, consulte les recettes et suis tes commandes directement sur le serveur Discord de la guilde.

/metier list Tous les métiers de la guilde.

/metier who Trouver un artisan par métier, niveau ou recette.

/metier recettes Voir les recettes connues d’un personnage.

/metier set Déclarer un métier manuellement.

/craft order Passer commande à un artisan.

/craft list Consulter les commandes en cours.

/craft accept Accepter une commande.

/craft done Signaler une commande terminée.

/craft cancel Annuler une commande.

/link Lier tes personnages à Discord.

/main Choisir ton personnage principal.

/export-addon Exporter l’annuaire vers le jeu.

/import Importer tes métiers depuis le jeu.

Avant l’installation

Questions fréquentes

Le compagnon est-il sûr ?

Il lit les fichiers de données que WoW écrit et dépose un fichier de données pour l’addon. Il ne demande pas de mot de passe ou d’adresse e-mail. Le code du projet peut être consulté sur GitHub.

Mes personnages hors guilde sont-ils enregistrés ?

Non. L’addon vérifie que le personnage appartient à FORMER HOPE avant de scanner ses données.

Pourquoi mes recettes n’apparaissent-elles pas ?

Ouvre la fenêtre de chaque métier une fois en jeu. Les données seront transmises à la prochaine déconnexion si le compagnon tourne.

Comment passer une commande de craft ?

En jeu, ouvre /gp, sélectionne un artisan et choisis une recette. Sur Discord, utilise /craft order.
